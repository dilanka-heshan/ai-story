# Locked Visual Style — Version 1

## Goal
Emotionally grounded, **premium stylized 3D animated film** for adult, everyday stories, NOT exaggerated cartoon slapstick. Works for romance, work stress, financial challenges, travel and life milestones.

## Prompt style block (paste unchanged into every image prompt)
High-end stylized 3D animated feature-film frame; mature but appealing character proportions; expressive natural eyes; believable anatomy; restrained facial acting; richly textured fabric and environments; soft cinematic global illumination; warm practical lights balanced against cool ambient light; carefully framed storytelling shot; subtle depth of field; detailed yet uncluttered composition; consistent character identity and design; emotionally sincere mood; vertical 9:16 composition; no visible text, no watermark.

## Consistency rules
- Characters: use approved visual references, not description alone.
- Do not change eye shape, skin tone, hairstyle, face geometry or relative heights between shots.
- Keep outfit unchanged unless the screenplay explicitly requires a change.
- Props and room arrangement must match prior shot.
- Film language: natural gestures and restrained acting, not rubbery exaggeration.

## Avoid
Hyperrealistic live-action skin, anime line art, inconsistent character scale, oversized baby-like features, random new outfits, distorted hands, duplicate limbs, floating objects, text overlays, inconsistent lighting direction.

## Locks
- Default frame: vertical 9:16
- Default story: 30–45 seconds, ~5–7 shots
- Character references: record filenames in each prompt
- Never overwrite approved reference assets
