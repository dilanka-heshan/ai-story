# One-episode pilot: Production stages

## 00 — Success criteria
- Goal: 30–45 sec emotional story, 9:16 vertical, stylized mature 3D look.
- 5–7 shots, manageable motion, only 1–2 characters, 1–2 locations.
- Test consistency, continuity, quality, duration, and production cost.

## 01 — Story planning (ChatGPT)
- Finalize hook (0–3 s), setup, tension, turning point, ending.
- Save brief, screenplay, and shot list; each shot includes narrative goal and approximate seconds.
- Approve: understandable without long narration; visually tellable.

## 02 — Lock style and characters (ChatGPT Images)
- Complete style bible, character bible, and generate front/side/3-quarter/expressions.
- Approve exactly one master character sheet per character, plus joint height comparison.
- Don't revise the master halfway through an episode. Save revision IDs for later episodes.

## 03 — Make keyframes (ChatGPT Images)
- Write one image prompt per shot using the template.
- Attach approved character sheets as references each time.
- Use vertical 9:16, repeat the same visual language, vary composition and expressions.
- For challenging interactions, first generate an anchor image clearly showing who does what.
- Review outfits, faces, background, hands, and props before animation.

## 04 — Animate shots (Google Veo)
- Make one controlled action per shot (e.g. turns head, puts mug on table).
- Supply keyframe/reference where Veo interface supports it.
- Record duration, image/video input files, aspect ratio, chosen model, audio setting, and complete prompt.
- Preview low-cost generations where available; regenerate only when a specific defect is identified.
- If voice/dialogue is unstable, generate silent shots and add audio in editing.

## 05 — Edit (CapCut)
- Import approved clips. Remove awkward starts/ends; align cuts with actions.
- Add narration/dialogue if needed, properly licensed soundtrack, ambient effects, captions.
- Keep music lower than speech and avoid random hard audio cuts.
- Export vertical 1080x1920 where available; review phone-screen readability.

## 06 — QA + publish
- Complete quality checklist, save final export outside Git (or LFS), thumbnail and captions.
- Keep proof of rights/licenses for music, voice, and generated assets.
- Check YouTube/Meta policies for disclosure of synthetic/altered content as applicable.
- Log actual total credits, total time, number of generations, and what to improve next time.
