# Script prompt template — ChatGPT

ROLE: You are an animation screenwriter and short-form film director.
TASK: Write a 35–40 second, 9:16, emotionally grounded 3D animated short for a recurring married couple.
INPUTS: `docs/style-bible.md`, `docs/characters.md`, `episodes/ep001/brief.md`.
REQUIREMENTS:
- Strong visual hook in first 3 seconds.
- Six shots, ideally 4–8 seconds each, one easy-to-animate action per shot.
- Everyday-life conflict, believable reactions, hopeful ending, no forced romance.
- Keep same outfits, location, props and time-of-day throughout.
- Minimize lip sync; use optional voice-over separately.
OUTPUT: Beat sheet + per-shot scene, duration, action, camera, lighting, audio cues, continuity notes + concise optional voiceover.
Do not invent physical traits; ask to fill blank character-bible fields before generating character prompts.
